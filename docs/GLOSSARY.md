# Glossary

| Term | Meaning |
|---|---|
| Application | A citizen's request for a configured service |
| Service | A published service definition citizens can apply for |
| Workflow definition | Versioned rules describing stages and transitions |
| Workflow instance | A running workflow for one application |
| Task | A unit of work assigned/claimed by an officer or queue |
| Grievance | A complaint or service-related issue |
| SLA | Target processing time and escalation policy |
| RBAC | Role-based access control |
| ABAC | Attribute-based access control; may supplement RBAC for scope |
| DTO | Data Transfer Object at an API boundary |
| JPA | Java Persistence API |
| ORM | Object-relational mapping |
| Outbox | Database record used to reliably publish events after commit |
| Idempotency | Repeating an operation does not create duplicate effects |
| BOLA | Broken Object Level Authorization |
| RPO | Recovery Point Objective; acceptable data loss window |
| RTO | Recovery Time Objective; acceptable recovery duration |
| SLO | Service Level Objective |
| ADR | Architecture Decision Record |
| E2E | End-to-end test |
| PII | Personally identifiable information |
