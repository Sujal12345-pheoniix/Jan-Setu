# Release Plan

## V0.1 – Engineering foundation
Repository, Spring Boot, React, PostgreSQL, Flyway, error handling, CI, health endpoint.

## V0.2 – Identity and authorization
Registration, login, session lifecycle, roles, permissions, department scope.

## V0.3 – Catalogue and applications
Service versions, dynamic form validation, drafts, submission, tracking.

## V0.4 – Documents and workflow
Private storage, verification states, tasks, clarification, decisions, history.

## V0.5 – Grievance management
Registration, assignment, response, resolution, appeal, feedback.

## V0.6 – SLA and notifications
Policy versioning, deadline calculation, scheduler, escalation, in-app/email delivery.

## V0.7 – Reporting and hardening
Dashboards, safe exports, query optimization, test coverage, accessibility improvements.

## V0.8 – Advanced architecture
Outbox, Kafka, Redis use cases, optional service extraction, optional Kubernetes.

## V1.0 – Portfolio release
Deployment, monitoring, security review, load test, restore drill, documentation, demo video.

A release is a milestone only when acceptance criteria and evidence are complete. Feature count alone does not determine release readiness.
